# Contributing to StewardMesh

Use short-lived branches such as `feat/REQ-ATLAS-001`, `fix/ISSUE-123`, `docs/DOC-001`, and `hotfix/SEC-001`. Do not push directly to `main`.

Pull requests must link an issue and requirement, explain scope, include tests, update documentation, identify migrations/API changes, address security and accessibility impact, and include screenshots for UI changes. Commits must include DCO sign-off.
