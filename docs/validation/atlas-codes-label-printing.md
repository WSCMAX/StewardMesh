# Atlas Codes label-printing validation

Requirement: `REQ-ATLAS-CODES-001`
Feature: `inventory.identifiers`
Issue: [#62](https://github.com/WSCMAX/StewardMesh/issues/62)

## Automated evidence

- `internal/atlascodes/labels_test.go` validates Code 128-B structure, checksum/stop generation, 10-module quiet zones, QR four-module quiet zones, immutable custom Pattern-driven geometry (including IDs containing `--`), renderer field parity, consistent unsupported-text rejection, physical overflow, safe QR routes, one-page SVG, two-page PDF, 8/12-dpmm ZPL geometry, test-marker separation, batch bounds, cancellation, byte-bounded caching, exact snapshot replay after artifact eviction, explicit replay expiry, authorization rechecks, and absence of confidential fields.
- `internal/atlascodes/testdata/zpl/code128-v1.zpl` and `qr-v1.zpl` are immutable 8-dpmm golden fixtures. Tests compare every generated byte and verify printer-language metacharacter escaping.
- `internal/httpapi/server_test.go` verifies CORS access to the idempotency and artifact headers, CSRF, immutable template metadata, physical output headers, exact retry bytes, vector PDF/SVG media types, write-only/read-only denials, resource-scoped visibility, ownership locks, denial redaction, and no duplicate association after generation.
- `web/src/AtlasLabelPrint.test.tsx` verifies keyboard-accessible cross-asset selection, visible dimensions, one-label SVG/multi-label PDF selection, disabled controls and stale-response suppression during generation, cancellation/retry, and that no print/download action occurs before explicit operator confirmation.

## Browser/OS print protocol

1. Use a current supported browser at desktop width and 320 CSS pixels. Confirm every selector, dimension, warning, preview, confirmation, and action remains visible without page-level horizontal overflow.
2. Generate the single-label SVG test print. Confirm the preview shows the exact template version, count, width, height, margin, quiet zone, and test-print state.
3. Confirm no dialog opens before the operator checks the review statement. After confirmation, open the browser dialog and verify no printer is preselected by StewardMesh.
4. Print at 100% scale with margins disabled only when the printer driver requires it. Measure the outer calibration rectangle with a physical ruler; each dimension must be within 0.5 mm of the displayed value.
5. Scan the Code 128 and QR output five times from 15–45 cm under normal office light. All reads must resolve the expected authorized asset. The QR decoded value must be `/atlas/codes/{opaqueIdentifierId}` and contain no session, credential, grant, raw private code, directory value, serial number, hostname, or deployment note.
6. Repeat with vector PDF through the browser PDF viewer. Confirm each selected label is a separate page with the declared physical size and remains sharp at 400% zoom.

## ZPL real-device qualification

ZPL is currently an exported renderer adapter, not a direct printer transport or an advertised supported-device claim. A model can be added to the supported table only after an operator records all of the following against the checked-in fixtures:

1. Printer manufacturer/model, firmware, dpi/dpmm, connection class, media stock, ribbon/direct-thermal mode, darkness, speed, and calibration date.
2. Raw fixture SHA-256, transfer command or spooler path, and evidence that no StewardMesh session or printer credential entered the label bytes.
3. Five successful scans per symbology at 15, 30, and 45 cm, measured physical dimensions within 0.5 mm, legible human-readable text, intact quiet zones, no clipping, and no unexpected printer-language command execution.
4. Power-cycle and media-reload repeat, a deliberately cancelled transfer, and an exact retry that produces one operator-requested label rather than duplicate associations.
